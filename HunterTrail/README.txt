Hunter Trail (WoW Forever addon) - a Beast Mastery hunter leveling companion, one tab per section

Install with WowUp (easiest, and it updates itself)
In WowUp, open Get Addons, choose Install from URL, and paste https://github.com/MrSustich/HunterTrail

Install by hand
1. Quit World of Warcraft.
2. Unzip HunterTrail.zip. You get a folder named HunterTrail.
3. Move the HunterTrail folder into:
   Windows: C:\Program Files (x86)\World of Warcraft\_forever_\Interface\AddOns
   Mac:     /Applications/World of Warcraft/_forever_/Interface/AddOns
   (Create the AddOns folder if it isn't there. It must be spelled AddOns.)
   If you installed the first version, replace the old HunterTrail folder.
   The path should end ...\AddOns\HunterTrail\HunterTrail.toc, not HunterTrail\HunterTrail\.
4. Start the game. On the character screen, open AddOns and make sure Hunter Trail is ticked.
   If it says "Out of date", tick "Load out of date AddOns" for this one.

Use
/trail            show or hide the window
/trail 40         open the Level Walkthrough for level 40
/trail talents    open a tab by its first word (gear, dungeons, class, pets ...)
/trail reset      move the window back to the middle
/trail minimap    hide or show the minimap button
Click a section on the left to switch tabs. On Level Walkthrough, < and > change the
level range and "My level" jumps back to yours. It follows your level as you ding.
Scroll with the mouse wheel. Drag the window to move it. It remembers where you put it.
