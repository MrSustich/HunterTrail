# HunterTrail

A WoW Forever leveling companion for a Beast Mastery hunter: level walkthrough, talents, professions, gear, dungeons, class quests, pets and more, in one in-game window. Type `/trail` in game.

Install or update with WowUp: Get Addons, Install from URL, and paste this repo's address. Each update is a GitHub release with a HunterTrail zip attached.
